# lilgatchi

Hello, world! This is lilgatchi, a digital pet project.

## How to play

Open `index.html` in a web browser. No installation is needed.

Your critter gets a little hungrier every 5 minutes. Press **Feed** to keep it full. If it stays hungry, its health drops. Its progress is saved in your browser, and time keeps passing while the window is closed.

The **Debug** tab has testing tools, including a switch that makes time pass twice as fast.
